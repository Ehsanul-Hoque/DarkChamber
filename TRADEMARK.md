# Trademark policy

DarkChamber's **code** is free software under the [GPLv3](./LICENSE): you may use, study, change
and share it, including in a fork, on the license's terms.

The **name "DarkChamber" and its logo are not covered by that license.** They identify builds
published by this project, so that someone installing "DarkChamber" knows whose promise about their
files they are trusting. For a security product that matters: a clone under the same name could
carry different code and the same reputation.

## What you may do without asking

- **Refer to the project by name** — in articles, reviews, talks, comparisons, package listings
  that redistribute the official, unmodified builds, and in your own project's description
  ("a fork of DarkChamber", "compatible with DarkChamber's `.dchm` format").
- **Fork the code and build it**, for yourself or for others, as long as a modified version you
  distribute goes out **under a different name and without the logo**.

## What needs a different name

- Distributing a modified build — on an app store, a website or anywhere else — as "DarkChamber",
  or under a name or icon close enough to be confused with it.
- Using the name or logo in a way that suggests this project endorses or maintains your build,
  service or product when it does not.

## Questions

If you are unsure whether a use is fine, open an issue on this repository and ask before shipping.
